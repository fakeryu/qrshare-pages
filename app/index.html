连接 GitHub 账号

qrshare 把文件存放在你自己的 GitHub 仓库，通过 GitHub Pages 生成公开链接。 需要一次性授权，之后自动记住。

  1. 1
    打开 GitHub 令牌创建页（已预填好所需权限） 点击打开 →
  2. 2
    页面底部点 Generate token，复制生成的 ghp_ 开头字符串
  3. 3
    粘贴到下面，点连接
关于安全（建议先看）
  • 令牌只保存在你这台设备的浏览器里（localStorage），不会上传到任何第三方服务器——本应用是纯静态页面，没有后端。
  • 权限范围：上面链接预填了 repo 权限，它对这个账号的 所有仓库都有读写权（不限于分享文件的那个仓库）。这是创建仓库所必需的。 介意的话可以改用 GitHub 的 fine-grained token，手动建好 qrshare-pages 仓库后只授权给它一个仓库。
  • 共用/公共电脑用完后务必点右上角「退出」，否则下一个人能以你的身份传文件。
  • 建议给令牌设置过期时间（如 90 天），到期重新生成即可。
  • 随时可在 GitHub Settings → Developer settings → Personal access tokens 撤销，撤销后本应用立即失效。
